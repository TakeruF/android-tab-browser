# Nagi 0.2.0

- Open supported external app links, including Google Play links, from web pages.
- Add an optional setting to block external app launches (off by default). A compact, nonmodal notice lets you allow a launch once or turn off blocking.
- Save left/right Split tab pairs and restore them after switching tabs or restarting Nagi.
- Drag a Split pair by its outer frame to reorder both tabs together, pin the pair, or move it to another Space.
- Keep both cards visible in the drag preview and fade the entire source pair consistently.
- Refine notification spacing, corner radii, and Simplified Chinese wording.

Install this APK over an existing GitHub installation to retain local data. The Google Play edition receives updates through Google Play; switching distribution channels does not support an in-place update.
