# Nagi 0.1.1

- Fix keyboard selection in Split so subsequent actions target the selected right-hand tab.
- Protect both visible Split pages from Archive.
- Fix uppercase HTTPS search templates and extension-based upload filters.
- Restore saving, viewing, and removing Bookmarks, including access from the Command Bar.
- Add cookie, site-storage, and page-cache clearing while retaining tabs, Bookmarks, and history.
- Add link/image long-press and right-click menus: open a new tab, copy/share URLs, and save images.
- Preserve the requested URL immediately during stalled initial navigation and allow recovery after a loading timeout.
- Add in-app update checks, APK downloads, size/checksum/signature validation, and Android's installation confirmation.
- Refine copy/share button spacing in both address bars and the Space selection frame.

The APK uses the same distribution signature as Nagi 0.1.0 published at takeruf.com/nagi. Open it to update in place and keep your workspace. Version 0.1.0 has no updater, so install this APK manually once; future updates can be checked in Settings → App updates.

Requires Android 8.0 or later. This is a signed, non-debuggable Release build. Local Debug builds and the former `com.orbit.browser` package are separate signing/package identities.
