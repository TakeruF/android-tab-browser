# Nagi 0.1.1

- Splitの右タブをキーボードで選択した後、操作が左ページへ向かう不具合を修正。
- 表示中のSplitページをArchive対象から除外。
- 大文字HTTPSの検索テンプレートと、アップロードの拡張子指定を修正。
- Bookmarksの保存・閲覧・削除と、Command Barからの呼び出しを追加。
- Cookie・サイトストレージ・ページキャッシュの消去を追加。タブ、Bookmarks、履歴は保持。
- リンク／画像の長押し・右クリックメニューを追加。新規タブ、URLコピー／共有、画像保存に対応。
- ページの初回読み込みが停滞しても要求URLを保存し、タイムアウト後に再試行できるよう改善。
- 設定からのアプリ内更新を追加。新バージョンの確認、APKダウンロード、検証、Android標準のインストール確認に対応。

0.1.0と同じNagiの署名を維持します。APKを開いて上書き更新してください。0.1.0には更新機能がないため、今回のAPKを手動で導入すると、次回からアプリ内で更新を確認できます。

Android 8以降に対応。配布APKは署名付きReleaseビルドです。
