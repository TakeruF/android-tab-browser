# Nagi 1.0.0

- Narrow windows use full-width pages, a bottom navigation bar, and a sheet for tabs, Favorites, and Spaces. Windows at least 600dp wide retain the sidebar.
- Mobile site mode identifies as a phone, including supported User-Agent Client Hints. Explicit per-site desktop/mobile choices remain in control.
- Resizing preserves the current document, unfinished form input, hidden tabs, and Split pages. Automatic site-mode changes apply on the next document navigation or manual reload.
- Advertisement blocking now collapses empty containers around confirmed blocked advertisements while preserving article text, images, and controls. Late page changes and pause/resume are handled.
- Compact system navigation colors follow the current theme and Space color.

Android 8 or later. Website behavior depends on its implementation and the installed WebView. Physical fold transitions and all advertisement patterns have not been verified.
