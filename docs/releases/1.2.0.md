# Nagi 1.2.0

VersionCode 17. Google Play is the sole official distribution channel.
Status on 2026-11-09: code 17 accepted by Google Play and submitted for a full production rollout. Publishing overview shows Changes in review with quick checks running and Managed publishing off. Approval/public availability is not yet confirmed. See [verification and submission](../RELEASE_1.2.0_VERIFICATION.md).

- Add Settings → General → Use Spaces with an explanation and confirmation before either change. Turning Spaces off keeps the current Space as a single tab list; other Spaces and tabs remain stored. Search and closed-tab restoration stay within the current Space until Spaces are enabled again. Favorites, pins, Split and live pages remain available.
- Declare Android's browser application category so browser pickers can recognize Nagi.
- Prevent a crash when private browsing closes before its WebView profile has been created.
- Preserve shipped camera-position calibration and left-only landscape spacing, video pop-out/PiP policy, and private-tab lifetime and keyboard privacy requests.

Local validation passed 180 Play Debug unit tests, Debug/Release lint (zero errors, 72 warnings each), Debug/test APK builds, and 29 selected API-36 instrumentation cases covering Spaces, Split/live drafts, camera calibration, private storage/lifetime, Reader, and video PiP. Signed artifact verification and Play state are recorded separately. Physical-device behavior is not established by emulator checks. Keyboard learning suppression remains a request to the installed IME; private tabs remain memory-only and do not survive process death.

See the [four-language Play notes](../play-store/release-notes-1.2.0.txt).
