## Settings retention changes

- Preserve older manual web/AI search choices when the automatic-region
  preference did not yet exist. Explicit automatic choices and fresh-install
  defaults keep their existing behavior.
- Use the same decoder when observing preferences and making atomic updates.
  Temporary read I/O failures retry instead of emitting empty/default settings
  and ending the observer. Startup seed-marker reads also retry.
- Keep the last observed settings and disable readiness on corruption or other
  unexpected read errors, using the existing workspace error screen. Read
  recovery does not clear or rewrite preferences.
- Save a new download-folder choice before releasing the old grant. Keep grants
  still used by the normal workspace when private-workspace choices change.
