# Nagi 1.3.0

## Replacement candidate: code 19

Status on 2026-11-15: code 19 has been accepted by Google Play and submitted for
full production rollout with the approved six-language notes and six-language
store copy. Console shows Changes in review, quick checks running and Managed
publishing off. Public code-19 availability is not yet confirmed; code 18 is now
published. The replacement includes all current development changes.

In addition to the code-18 features below, this candidate includes:

- Spanish and French interfaces, bringing the app to six languages.
- Single-page compact browsing while retaining saved Split pairs for wide windows.
- Revised theme palettes, Space colors, color presets and custom color editing.
- A Command Bar settings category for suggestion visibility and a simpler list.
- A selectable download folder, with Downloads fallback if access is lost.
- Settings layout and surface refinements, an open-source licenses screen, and
  an About row that opens Google Play for updates.
- Rounded, themed link/image drag cards and pill-shaped address-bar feedback,
  two mobile/desktop choices, and removal of redundant Split side labels.
- Enable Android password autofill in normal browsing, including the system
  service picker and manual retry. Provider approval and Google credential delivery
  remain unverified; private browsing and Reader remain excluded. Diagnostics stay
  Debug-only.

The original `v1.3.0` tag and code-18 notes are historical and remain unchanged.
The replacement uses the distinct `v1.3.0-code19` tag at source
`7fadfab18581a3e2ecb295e119887e4789e2610b`.

## Historical code-18 submission

VersionCode 18. Google Play is the sole official distribution channel.
Status on 2026-11-15: code 18 accepted by Google Play and submitted for a full
production rollout. Publishing overview shows Changes in review, quick checks
running and Managed publishing off. Approval/public availability is not yet

The feature source is committed baseline `f5a3093`. Existing uncommitted changes
in the original checkout are excluded from the release. Immutable tag `v1.3.0`

- Add whole-page zoom controls to the page menu, with native zoom in/out and
  reset. Ctrl/Command + plus, minus and zero operate on the visible, focused
  page. Retained live pages keep their scale; in-memory snapshots restore the
  relative scale, reset baseline and scroll position.
- Add “Continue browsing” to new tabs, showing up to four current-Space pinned
  tabs and saved Split pairs. A saved pair occupies one entry and restores its
  two existing pages.
- Add keyboard actions for History, Settings and supported private browsing.
  History/Settings also work from the foreground Omnibox. Preserve CJK
  composition and exclude page zoom behind browser overlays.
- Reorganize Settings into General, Appearance, Search engines, Tabs, Video,
  Privacy and About categories. At 760 dp of available Settings content width,
  show categories and details side by side; narrower windows use list/detail
  navigation. Keep category selection through resizing and Activity recreation,
  hide the browser sidebar while Settings is open, and show the installed
  version once in About.
- Improve HTTP download progress presentation and add progress/completion
  notifications for page-generated files. Use a confirmation matching browser
  notice cards. After a confirmed HTTP download is accepted, automatically close
  an empty tab opened by a live page while preserving its opener and saved Split.
  Cancellation, manually created tabs and pages that already displayed a
  document keep their tabs.

## Limitations

Native website viewport limits still apply to page zoom. This adds no persisted
per-site zoom preference or guarantee of DOM/form recovery after process death.
Generated downloads remain limited to 32 MB and the live page/host lifetime;
notification appearance and permission depend on Android and the device.
Private browsing still requires supported WebView isolation. Password autofill
remains behind its existing production approval gate. Physical keyboards,
physical devices, other WebView providers and arbitrary live websites are not
established by selected emulator tests.
