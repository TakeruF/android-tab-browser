# Nagi 0.1.2

- Upload photos using Android camera capture and the document picker.
- Save page-generated Blob/data downloads up to 32 MB after confirmation.
- Drag links and images with native Android drag and drop; drop URLs onto either pane address bar.
- Suspend eligible idle background tabs and restore their browsing history when reopened.
- Use the selected Android password autofill provider for website forms.
- Improve sidebar split-tab dragging and pane interactions.
- Add regional AI search choices, including Qwen for the China region.
- Separate GitHub APK updates from Google Play delivery. The Play edition does not include an APK installer.

Install the GitHub APK over the existing GitHub 0.1.0/0.1.1 installation to retain local data. The Google Play edition uses a different Play app-signing certificate; switching between distribution channels does not support an in-place update. Physical camera hardware, third-party drop destinations, and OEM password-provider behavior remain device-dependent.
