# Nagi 1.6.1 / code 25

Status: release preparation authorized on 2026-11-26 for the existing Google
Play production track. Upload, review submission and public availability are
not yet confirmed.

- Back/Forward previews now follow two-finger trackpad navigation in both
  directions. Recent departing viewports survive SPA transitions and a
  three-step Back/Forward round trip.
- YouTube-style same-document navigation records browsing history. Delayed
  titles update the existing visit without creating duplicate rows.
- Right-click text selection uses the native horizontal long-press toolbar.
  App-owned permission, photo/file-choice and link/image dialogs share Nagi's
  existing themed design.
- Microphone capture includes the Android audio-settings permission required
  by WebView. Downloading into a chosen folder requests notification permission
  for Nagi's completion notification; denial still allows the file to save.

## Scope and limitations

Previews are memory-only, retaining the current viewport and three recent
destinations. Restored, evicted or resized entries may use the destination-URL
fallback. Native selection actions and timing depend on Android/WebView.
System permission/picker/share screens and provider JavaScript dialogs retain
their platform presentation.

The release adds the normal `MODIFY_AUDIO_SETTINGS` permission without a new
database migration or a change to optional hardware requirements. It adds no
background recording or new collection service. Physical trackpads, OEM menus,
camera/GPS hardware, microphone quality/headset routing and completed ChatGPT
voice sessions remain outside the verified scope.
