# Nagi 0.1.3

- Simplify navigation by removing the separate bookmark library and redundant page-menu saving actions. Favorites remain available through sidebar drag and drop and tab menus.
- Refine Simplified Chinese wording across settings, search, downloads, tab suspension, and update prompts.
- Retain existing browsing data and Favorites when updating within the same distribution channel.

Install this APK over an existing GitHub installation to retain local data. The Google Play edition receives updates through Google Play; switching distribution channels does not support an in-place update.
