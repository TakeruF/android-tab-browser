# Nagi 1.1.3

VersionCode 12. Google Play is the sole official distribution channel.

- Prevent ordinary page videos, including autoplay, from automatically opening Android picture-in-picture when returning Home.
- Continue PiP playback from fullscreen videos or an existing in-app video pop-out. Leaving fullscreen disables automatic Home/PiP again.
- Update the PiP setting description in English, Japanese, Simplified Chinese and Korean.

See the [four-language Play notes](../play-store/release-notes-1.1.3.txt). Source tags and release notes do not establish Google Play availability.

Local preflight on 2026-11-03 passed all 161 Play Debug unit tests, all 15 selected video and page-video compatibility instrumentation cases on API 36, and Debug/Release lint with zero errors (72 warnings each). Coverage includes autoplay Home/PiP exclusion, manually started inline video, fullscreen exit, fullscreen/pop-out PiP, cross-origin frames, source-tab return, mouse resizing, page zoom, viewport resizing and independent saved settings. Physical ColorOS and Play-delivered runtime checks remain outside this evidence.
