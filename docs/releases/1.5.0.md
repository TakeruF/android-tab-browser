# Nagi 1.5.0 / code 23

Status: local release candidate prepared on 2026-11-24. Google Play upload,
review submission and public availability are not yet established.

This minor release refreshes search and customization, improves workspace
organization and fixes interaction and video presentation regressions.

- Search follows the address bar in wide windows and expands to a top-aligned
  phone surface above the keyboard. Settings can restore the previous centered
  layout; the migration tip can be dismissed.
- Compact spacing supports always off, physical-keyboard automatic (default)
  and always on. Theme and compact choices use current-value menus.
- New-tab background settings have a preview and mode-specific controls.
  Popups consume their own input instead of activating controls underneath.
- History recording, suggestions, display and per-Space deletion are separated
  by Space. Room v4 retains IDs/timestamps and assigns older shared history once
  to Personal or the first existing Space, without duplicating it. Favorites
  and ordinary site sign-in remain shared.
- Collapsed sidebars show the current Space and a narrower rail with compact
  spacing. Tab icons support Split dragging. Favorites stay visible during
  dragging and use equal left/right Split targets. Existing Split drops open
  the selected side while retaining the partner's live page and draft.
- Phone Space swipes keep the tab sheet open. CJK composition and live page
  retention remain supported through layout, theme and keyboard changes.
- Completed system PiP returns a resumed video to fullscreen. Repeated source-
  tab switches retain one native surface instead of overlaying another tab.
- Page-history back previews, popup sizing, page notices, favicons and bare-host
  navigation recovery include the documented local fixes.

## Scope and limitations

Actual external passkey selection, QR and provider authentication remain
unresolved/unverified. This release does not claim new Google privileged-browser
approval. No analytics collection was added. Physical/OEM devices and arbitrary
sites are separate from the selected emulator/local-fixture checks. A recorded
horizontal mouse-wheel emulator/provider regression remains unresolved; the
preceding comparison APK showed the same behavior.
