# Nagi 1.1.1

Google Play release candidate — not yet submitted. Starting with 1.1.1, Google Play is the sole official distribution channel. GitHub tags and release notes record source versions; no new public APK or updater manifest is published.

Install and update through [Google Play](https://play.google.com/store/apps/details?id=com.takeruf.nagi).

- Add a per-site **Use device default view** option for sites that do not work correctly in desktop view.
- Show a dismissible retry hint when Cloudflare Turnstile reports a failure in desktop view. Switching views and reloading requires an explicit tap.
- Keep display-mode state consistent after cross-host attachment downloads and restore the source site’s chosen identity on reload.
- Preserve the opener's browser identity and cookie policy while handing off a new-window request.
- Add an optional bottom search bar for narrow layouts and refine compact browser controls.

The [verification record](../RELEASE_1.1.1_VERIFICATION.md) distinguishes emulator coverage, physical-device authentication observations, and remaining live-account limitations.

Existing GitHub/website APK installations have a different signing identity from Play. An in-place channel switch is not guaranteed, and uninstalling removes app-private data. See [migration guidance](../RELEASING.md).

See [final Play preparation](../RELEASE_1.1.1_PLAY_PREPARATION.md) for the reviewed source, signed upload artifact and saved Console stop point.
