# Nagi 0.2.1

- Keep a single history entry while the same tab reloads, rotates, or switches between desktop and mobile display. Returning after visiting another page remains a separate visit.
- Remember desktop/mobile display choices for each website across links, tab restoration, and app restarts.
- Avoid extra requests to the previous page when a link or redirect needs a different display mode.

Install this APK over an existing GitHub installation to retain local data. The Google Play edition receives updates through Google Play; update within your current distribution channel.
