# Nagi 1.3.1

VersionCode **20**. Google Play is the sole official distribution channel.
Status on 2026-11-15 (JST): release preparation; no code-20 upload, review
submission or public availability is established yet.

## Changes

- Add optional adaptive dark mode for web pages, off by default. Enable it in
  Appearance settings; it applies only with the effective dark app theme. The
  page menu can disable/re-enable adaptation per website, retaining the choice.
  Both live Split panes update without reloading pages or losing drafts/scroll.
- Center the empty new-tab search field and remove its redundant Space heading.
  Initial Enter no longer accidentally activates the sidebar toggle; explicit
  keyboard navigation and Command Bar input remain available.
- Widen the sidebar boundary's drag target. Show a neutral gray guide only
  during a drag, retaining collapse/reopen and cancellation behavior.
- Hide Command Bar Space suggestions effectively while Spaces are off, retaining
  the user's saved choice for re-enabling Spaces.
- Remove GitHub, Google Scholar, Wikipedia and YouTube from new-install search
  engine seeds. Preserve existing saved engines and selections.
- Use the same adaptive Settings category/detail structure for search-engine
  customization as for licenses; retain category and child navigation through
  resizing/recreation, and fit action controls within narrow rows.
- Remove the redundant download-confirmation close icon and duplicate Forward
  menu action where a separate navigation button already exists.
- Remove the stale app version from the bundled third-party-notices heading.

## Limitations

Adaptive dark mode requires a supported Android System WebView. The site switch
controls Nagi's automatic adaptation; authored dark themes and author opt-outs
remain under website control, and colors/contrast can vary. Local emulator
checks do not establish arbitrary website compatibility, physical-device
behavior or recovery of live drafts after process death.
