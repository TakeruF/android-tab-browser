# Nagi 1.1.0

- Translate web pages on your device with Google Translate through ML Kit, remember the target language, and continue translating same-language pages followed within the same tab. Optional language rules can translate matching pages automatically.
- Translation controls use a compact page notice and a single status bar with a Show original action.
- Google sign-in rejection pages in desktop mode offer a mobile-view retry. The choice is remembered for the Google sign-in host.
- Customize the new-tab background and appearance.
- Favorite menu buttons have a smaller touch area, and long presses no longer leave Favorite icons hidden after a drag.
- Improve sidebar layout stability when rotating or resizing the window.

Android 8 or later. Website compatibility and password-manager suggestions depend on the device, provider, and installed Android System WebView. Translation covers page text; images and PDF contents are not translated. Switching Google sign-in to mobile view may help, but does not guarantee authentication.
