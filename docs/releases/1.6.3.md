## Changes

- Fixed the disconnected authentication popup responsible for a Claude Google
  sign-in failure: retain the native child window, opener communication and
  request body through the tab handoff.
- Added Nagi to Android's selected-text web-search handlers, using the current
  default search engine.
- Added predictive-back previews when Back closes a tab and returns to its
  opener, another tab or the new-tab screen. Cancellation preserves live pages
  and drafts; the repository verifies the predicted destination before closing.
- Increased Back/Forward snapshot quality, keeping native viewport resolution
  where it fits the memory budget, with up to four megapixels per image and
  shared byte-bounded eviction across live engines.
