# Nagi 1.6.0 / code 24

Status: Google Play production publication was confirmed by the official
release lifecycle on 2026-11-26. This is the observation date, not the exact
publication time. The 100% rollout was submitted on 2026-11-25.

- Phone windows have a refreshed bottom toolbar and a right-aligned page-menu
  popup. The menu stays at the bottom with either address-bar placement.
- A Home button opens the new-tab home in the current tab, without creating or
  closing tabs. Android Back can return through the page's native history.
- Back, Forward, Copy link, Share and Reload stay fixed at the menu bottom while
  the other tools scroll. New tab, History and Settings are also available in
  the menu. Page sharing, copying and blocking actions move out of the phone's
  top address bar into the page menu.
- Phone tab lists and wide sidebar rows omit the separate three-dot button and
  retain Close. Phone tab lists use larger Close targets. Secondary-click menus,
  accessibility actions, dragging and saved Split pairs remain supported.

## Scope and limitations

The release changes browser controls, without a database migration or changes
to search, Space-scoped history, authentication providers or website rendering.
External passkey-provider login and the previously recorded horizontal-wheel
emulator/provider issue remain outside the verified scope. Physical devices
and arbitrary live sites require separate validation.
